🔧 智享论坛启动问题解决方案

如果你无法正常启动论坛，按以下步骤逐一检查：

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📋 第一步：检查 Node.js 安装

1. 按 Win+R 打开运行，输入 cmd，按回车
2. 在命令行输入：node --version
3. 如果显示版本号（ 如 v18.x.x），说明已安装
4. 如果提示"不是内部命令"，需要先安装 Node.js
   下载地址：https://nodejs.org/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🔍 第二步：使用诊断脚本

现在有一个新的"诊断启动.bat"文件：
1. 双击"诊断启动.bat"
2. 它会显示详细的错误信息
3. 不会自动关闭，你可以看到具体问题

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🚀 第三步：手动启动（最可靠）

如果脚本不行，可以直接用命令启动：

1. 打开命令提示符（cmd）
2. 依次输入以下命令：

   cd c:\Users\monica.wangzw.GOEROPTICS\.claude\forum-app

   echo MONGODB_URI=mongodb://localhost:27017/forum > .env.local
   echo JWT_SECRET=forum-secret-key-2024-production-ready-secure-auth-token >> .env.local
   echo NEXT_PUBLIC_SITE_URL=http://localhost:3000 >> .env.local

   npm install

   npm run dev

3. 看到 "Ready in xxx ms" 说明启动成功
4. 打开浏览器访问：http://localhost:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 💡 常见问题及解决方法

问题1："npm不是内部命令或外部命令"
解决: 需要安装 Node.js
答：下载安装 https://nodejs.org/

问题2：npm install 失败
解决: 使用国内镜像
答：
  npm config set registry https://registry.npmmirror.com
  npm install

问题3：端口3000被占用
解决: 使用其他端口
答：
  npm run dev -- -p 3001
  然后访问 http://localhost:3001

问题4：缺少某个文件
解决: 检查项目文件是否完整
确保以下文件存在：
- package.json
- tsconfig.json
- src/app/page.tsx
- src/app/layout.tsx
分别运行各个命令查看报错

## 📱 快速测试是否能在浏览器访问

1. 假设启动命令能持续不退出
2. 等待30秒-1分钟（首次编译需要时间）
3. 打开新的浏览器窗口
4. 输入：http://localhost:3000
